🖥️ Website Bán Linh Kiện Máy Tính — Đồ Án Môn CT113 (Nhập Môn CNPM)

Dự án xây dựng hệ thống website bán linh kiện máy tính phục vụ môn học Nhập môn Công nghệ phần mềm (CT113). 
Hệ thống thực hiện phân quyền sử dụng cho 4 nhóm đối tượng gồm Khách hàng, Nhân viên, Quản trị viên và Chủ cửa hàng.


🛠️ 1. Công Nghệ Sử DụngGiao diện (Frontend): HTML5, CSS3 (sử dụng Bootstrap qua CDN), JavaScript ES6+ thuần dạng ES module.
    Xác thực (Authentication): Firebase Authentication qua Email/Password.
    Cơ sở dữ liệu (Database): Cloud Firestore (NoSQL).
    Lưu trữ tệp (Storage): Firebase Storage (lưu trữ ảnh sản phẩm, avatar).
    Triển khai (Hosting): Vercel Static Hosting (triển khai tĩnh trực tiếp không cần bước build).
    Xử lý phía Server (Backend - Tuỳ chọn): Vercel Serverless Functions (Node.js) hỗ trợ nghiệp vụ tính lương.
